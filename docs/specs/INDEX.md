# Specs Index

Contract specs for the ZClassic23 power node. Each document in this
directory is a contract only — it defines surface (names, anchors,
behaviors that must hold). Implementations and adapters live elsewhere.

## Power Node

- **Power Node Architecture Contract**
  - Local contract: `docs/specs/POWER_NODE_CONTRACT.md`
  - Covers `node_state_api`, `service_registry`, onion gateway, ZClassicDNS,
    MCP surface, permissions, and event expectations.
