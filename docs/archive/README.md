# docs/archive — Period artifacts

Postmortems, reviews, and handoffs captured at a specific moment in
the project's history. Preserved verbatim, including any P-tag
shorthand (e.g. `P8.9`, `P10.1.2`) that predates the wave-5 doc
sweep. They describe the state of the code at the time they were
written, not current architecture.

Treat these as read-only history. Authoritative current docs live in
the parent `docs/` directory and in `CLAUDE.md` / `DEFENSIVE_CODING.md`
at the repo root.

## Layout

- `2026-04/` — BIP30 stall, chain-pin postmortem, P10.1.2 review.
- `2026-05/` — Fast-sync phase-7 handoff.

When archiving new period artifacts, drop them under
`YYYY-MM/` matching the date in the filename.
